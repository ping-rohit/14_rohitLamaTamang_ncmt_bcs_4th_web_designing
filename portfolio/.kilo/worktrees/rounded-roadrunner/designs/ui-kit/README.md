# UI kit

Reusable visual components used across the site, defined once in
`assets/css/style.css`:

- `.btn` / `.btn.filled` — outline and filled buttons
- `.stamp` — rotated double-bordered "stamp" badge
- `.skill-row` — skill matrix row with tick boxes
- `.credential` — double-bordered credential card
- `.case-card` — bordered project card
- `.field` — underline-style form input

See `designs/branding/colors/colors.md` and
`designs/branding/typography/typography.md` for the color and type tokens
these components use.
