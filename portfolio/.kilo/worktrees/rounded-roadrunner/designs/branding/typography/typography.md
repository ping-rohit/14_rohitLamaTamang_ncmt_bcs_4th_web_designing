# Typography

Two Google Fonts, loaded via CDN link tags in `index.html`:

| Font | Role | Used for |
|---|---|---|
| Bebas Neue | Display / heading | Big titles: name, section headings, stamps |
| Courier Prime | Body | Paragraphs, labels, buttons — gives a typewriter/report feel |

Rationale: the site is styled as a "case file" / dossier, so a typewriter
body font and a bold condensed display font support that theme better
than a standard sans-serif pairing.
